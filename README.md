# 💰 SpendWise – Personal Expense Tracker

SpendWise is a Python-based Personal Expense Tracker developed using **Python, Tkinter, and MySQL**. It provides a simple graphical interface to manage and track daily expenses efficiently.

The project aims to make personal expense management easier while demonstrating the practical implementation of Python programming and database connectivity.

## ✨ Features

- Add new expenses.
- View recorded expenses.
- Delete expenses.
- Store expense records in a MySQL database.
- User-friendly graphical interface using Tkinter.
- Real-time database connectivity using MySQL Connector.

## 🛠️ Technologies Used

- **Python 3** – Core programming language.
- **Tkinter** – Graphical User Interface (GUI).
- **MySQL** – Database management.
- **MySQL Connector** – Connecting Python with MySQL.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/NITINCODER-cyber/SpendWise2.git
```

### 2. Open the project folder

```bash
cd SpendWise2
```

### 3. Install MySQL Connector

```bash
pip install mysql-connector-python
```

### 4. Configure MySQL

- Install and start MySQL Server.
- Create the required database and expense table.
- Configure your database connection details in `db_config.py`.

### 5. Run the application

```bash
python main.py
```

## 🎯 Project Objective

The main objective of SpendWise is to develop a beginner-friendly expense management application while learning Python GUI development, SQL database management, and Python-MySQL connectivity.
